# Talaria 1.14.13 (versionCode 30)

- Links in chat now open with a single tap. Before, text selection or the bubble's long-press swallowed the tap. Web links open in your browser or the app that handles them, and file paths open in the viewer. Long-press still selects text and opens the menu.
- Bare `www.` links are now tappable as well.
- Same fix for links in headings, list items and tables.
