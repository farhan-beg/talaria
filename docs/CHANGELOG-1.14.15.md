# Talaria 1.14.15 (versionCode 32)

## Files
- File cards in replies stack full width instead of scrolling sideways: a "N files" header, type and folder under each name, and long names shortened in the middle so the extension stays visible.
- CSV and TSV open as a table: sticky header, row numbers, sized columns, search across rows, tap a row for the whole record (tappable links, Prev/Next). Raw text toggle in the menu.
- Large text files render lazily line by line with line numbers, fixing big CSVs and logs that failed to open.
- New in-app previews: video (player controls), audio (seek, ±10 s, speed), Word .docx, Excel .xlsx (sheet tabs), PowerPoint .pptx (slide cards), ODT/ODS/ODP text, HTML and SVG (offline, scripts off, view source), zip/jar/epub listings (open an entry, back returns to the archive), APK info, font specimens, animated GIFs, HEIC/AVIF.
