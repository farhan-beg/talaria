Running in two minutes.

Talaria is a client. It expects a Hermes Agent you already run, on your own box, on your network.

1

Run Hermes Agent

One command on your server: curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash. Keep the dashboard reachable over https, your LAN or a VPN.

2

Install Talaria

A single signed APK from GitHub releases. No Play listing, no account, no ads. New versions install right over the old one.

3

Point it at your server

Enter your dashboard address, sign in with the credentials you already use, and your agent is on your phone.

Fair questions.

Is this an official Nous Research app?

No. Talaria is an independent, community-built client. Hermes Agent itself is built by Nous Research under the MIT license, and this project is not affiliated with them. It just speaks the same gateway your dashboard does.

Where does my data go?

To your server, and nowhere else. Sign-in uses your own dashboard credentials, tokens are stored encrypted on the device, and the app has no analytics, crash reporting or telemetry of any kind.

Why is it not on the Play Store?

Sideloading keeps the release honest and instant: every version that gets built is the version you can download, signed on the same key since the first public release. Grab the APK, tap install, done.

Can I run more than one server?

Yes. Save as many as you like. Each keeps its own live connection, so a reply on server A keeps streaming while you chat on server B, and notifications bring you back to the right chat.
